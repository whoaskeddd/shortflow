# Техническое задание
# Проект: ShortFlow
# Версия: MVP
# Стек: Backend — Python FastAPI, Mobile — React Native

## 1. Описание проекта
ShortFlow — мобильное приложение для просмотра и публикации коротких вертикальных видео, похожее по пользовательскому опыту на TikTok и Reels. Приложение поддерживает ленту видео, профили пользователей, подписки, лайки, комментарии, сохранения, репосты, поиск и AI-модерацию контента.

## 2. Цели проекта
- Создать pet project с реалистичной архитектурой социального видеоприложения.
- Реализовать современный мобильный интерфейс с акцентом на UX.
- Построить backend с API, загрузкой видео, хранением данных и AI-модерацией.
- Показать навыки full-stack разработки на мобильной платформе.

## 3. Платформы
- iOS
- Android

## 4. Подход к разработке
Приложение разрабатывается на React Native с единым кодом для iOS и Android. Допускается использование платформенно-специфичных компонентов только там, где это необходимо для качества UX или системных особенностей.

## 6. Основной функционал

### 6.1 Регистрация и авторизация
- Регистрация по email.
- Вход в аккаунт.
- Выход из аккаунта.
- JWT access/refresh tokens.
- Восстановление пароля при необходимости.

### 6.2 Профиль пользователя
- Просмотр профиля.
- Редактирование имени, bio и аватара.
- Список опубликованных видео.
- Список подписчиков и подписок.
- Лента понравившихся и сохранённых видео.

### 6.3 Видео
- Загрузка вертикального видео.
- Добавление описания, хэштегов и обложки.
- Просмотр видео в полноэкранной ленте.
- Автовоспроизведение.
- Пауза, mute/unmute.
- Лайк, комментарий, сохранение, репост.
- Переход в профиль автора.

### 6.4 Лента
- Главная лента `For You`.
- Лента `Following`.
- Бесконечная прокрутка.
- Кэширование популярных элементов.
- Базовый механизм ранжирования.

### 6.5 Комментарии
- Просмотр комментариев.
- Добавление комментария.
- Удаление собственного комментария.
- Ответы на комментарии.
- Жалоба на комментарий.

### 6.6 Поиск
- Поиск по видео.
- Поиск по пользователям.
- Поиск по хэштегам.
- История поиска.

### 6.7 Уведомления
- Лайк видео.
- Новый комментарий.
- Подписка на пользователя.
- Статус модерации контента.

### 6.8 AI-модерация
- Проверка текста описания и хэштегов.
- Проверка комментариев.
- Проверка изображения обложки и, при необходимости, ключевых кадров.
- Статусы модерации: approved, needs_review, rejected.
- Сохранение причины модерации.
- Отправка спорных материалов в ручную проверку.

## 7. Требования к дизайну
- Современный минималистичный стиль.
- Визуальная стилистика в духе Apple и OpenAI.
- Мягкие цвета, чистые поверхности, много воздуха.
- Поддержка light mode и dark mode.
- Аккуратные анимации без перегруза.
- Высокая читабельность текста.
- Скругления, мягкие тени, премиальные акценты.
- Основной акцентный цвет: синий или фиолетово-синий.

## 12. MVP scope
### Включить
- Авторизация
- Профили
- Загрузка видео
- Лента
- Лайки
- Комментарии
- Подписки
- Сохранения
- Репосты
- Поиск
- AI-модерация
- Базовая админ-панель

### Не включать на MVP
- Live streaming
- Direct messages
- Duet / stitch
- Сложная ML-рекомендация
- Монетизация
- Профессиональный видеоредактор

## 13. Критерии готовности
- Приложение запускается на iOS и Android.
- Пользователь может зарегистрироваться и войти.
- Можно загрузить и посмотреть видео.
- Лента работает стабильно.
- Есть взаимодействия с видео.
- AI-модерация работает.
- Интерфейс выглядит современно и аккуратно.

## 14. Риски
- Сложность видео-стриминга и кэширования.
- Долгая обработка видео после загрузки.
- Сложности с модерацией мультимодального контента.
- Разрастание scope за пределы MVP.

## 15. Рекомендации
- Делать MVP максимально простым.
- Сначала реализовать core feed и upload.
- Модерацию подключить сразу, но без избыточной логики.
- Дизайн держать в стиле iOS-first, но без потери качества на Android.
